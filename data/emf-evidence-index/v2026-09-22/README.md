## What this release contains

A reviewed directory of regulators, national standards, precautionary
frameworks, research bodies, classifications, physician guidance, and studies
used in the RADIHALT EMF evidence library. Each record includes an editorial
evidence-role label, original reference, primary-source URL, and permanent
RADIHALT guide URL.

Files:

- `radihalt-emf-evidence-index-2026-09-22.csv` — tabular release
- `radihalt-emf-evidence-index-2026-09-22.json` — structured release with dataset metadata and limitations
- `radihalt-emf-evidence-index-2026-09-22.bib` — portable BibTeX citation

## Method and limitations

This is a curated discovery directory, not a systematic review or a ranking of
source quality. Source-role labels are RADIHALT editorial classifications. A
source's inclusion does not mean RADIHALT endorses every conclusion it
contains. The release is educational and is not medical advice.

All 23 primary-source URLs were checked on 2026-09-22. Four retired links were
replaced with current primary or official records from WHO, Brussels
Environment, the State of Salzburg, and PubMed.
